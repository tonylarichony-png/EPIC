# EXP-002 — 4-mer lookup

## До запуска

- **Гипотеза:** цельное ориентированное слово `[-3,0]` различает локальные
  мотивы лучше динуклеотида `[-1,0]` и улучшит ранжирование на новых contig.
- **Меняем:** только длину цельной категориальной последовательности: `k=2 → 4`.
- **Оставляем фиксированным:** полный train/validation, target `count > 0`,
  contig split, strand orientation, estimator, сглаживание и обе метрики.
- **Reference:** 2-mer lookup, рассчитанный тем же estimator. Ранжирование
  EXP-001 logistic regression показывается только как bridge-control.
- **Критерий принятия:** относительный прирост полного validation AP не менее
  1%, EPIC Spearman не ниже reference, AP выше reference минимум на двух из
  трёх validation-contig.
- **Notebook:** [[notebooks/experiments/EXP-002_4mer_lookup.ipynb]].

## Зафиксированный estimator

Окно `[-k+1,0]` рассматривается как одна категория: `4^k` канонических слов и
одна категория `N/edge`. Логистическая регрессия и one-hot не используются.

Для train prevalence `p` фиксируем одинаковую на всех уровнях силу prior
`tau = 1 / p`. Это соответствует одному ожидаемому pseudo-positive только
для global-prevalence prior. Для канонического k-mer число pseudo-positive
равно `tau * parent_score`. Для категории с `y` positives и `n` позициями:

`score_k = (y + tau * parent_score) / (n + tau)`.

У 2-mer `parent_score=p`; у 4-mer это score его конечного 2-mer. При `n=0`
получается точный backoff к parent. `tau` вычисляется только из train и не
подбирается по validation. Для отдельной learned-категории `N/edge` prior
равен общей train prevalence, поскольку однозначного канонического suffix у
неё нет.

## Результаты

Оценка выполнена точно на полном validation: 83 807 486 position-strand и
56 205 положительных позиций. Reference и candidate получили одинаковые
позиции, target и scorer.

| Метрика           | 2-mer reference | 4-mer candidate |        Delta | Относительно reference |
| ----------------- | --------------: | --------------: | -----------: | ---------------------: |
| Average Precision |     0.001330258 | **0.001486787** | +0.000156529 |            **+11.77%** |
| EPIC Spearman     |        0.090720 |    **0.094232** |    +0.003512 |             **+3.87%** |

### По validation-contig

| Contig | AP 2-mer | AP 4-mer | Spearman 2-mer | Spearman 4-mer |
|---|---:|---:|---:|---:|
| `NC_064034.1` | 0.001427969 | **0.001607096** | 0.101741 | **0.103728** |
| `NC_064041.1` | 0.001152619 | **0.001279664** | 0.109017 | **0.115822** |
| `NC_064042.1` | 0.001370618 | **0.001526589** | 0.111078 | **0.113193** |

Все три заранее заданных условия выполнены: относительный прирост AP больше
1%, Spearman не снизился, AP улучшился на 3 из 3 contig. 2-mer lookup также
воспроизвёл метрики EXP-001, поэтому переход от logistic representation к
lookup не создал скрытого разрыва в reference.

Опубликованные результаты `epic_solution` сохранены в notebook только как
внешний ориентир. У них другой split, edge-policy и submission-преобразование,
поэтому они не участвовали ни в критерии принятия, ни в выборе параметров.

## Решение

`adopt` — цельный ориентированный 4-mer даёт устойчивый дополнительный сигнал
и становится reference для EXP-003.
