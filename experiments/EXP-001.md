# EXP-001 — Динуклеотидный baseline

## До запуска

- **Гипотеза:** ориентированная пара DNA `[-1, 0]` содержит воспроизводимый
  сигнал и превосходит константный reference на validation-contig.
- **Меняем:** константный score на L2 logistic regression только по 17
  категориям ориентированного динуклеотида.
- **Фиксируем:** `contig_holdout_v1`, seed 42, pooled binary target, полный
  train/validation, `TT` как reference-категорию, `C=1`, `lbfgs`, L2.
- **Критерий успеха:** validation AP выше prevalence, EPIC Spearman больше
  нуля, solver сошёлся без `ConvergenceWarning`.
- **Notebook:** [[notebooks/experiments/EXP-001_dinucleotide_baseline.ipynb]].

## Точный вычислительный протокол

Модель имеет 17 возможных входов: 16 пар `AA…TT` и `N/edge`. Полные
228 064 160 train position-strand просканированы один раз и точно агрегированы
в `17 × 2 = 34` взвешенные строки по категории и target. Это не subsampling:
взвешенная log-loss совпадает с loss развёрнутой выборки. AP вычислен по всем
83 807 486 validation-позициям, Spearman — по всем 56 205 положительным.

## Результаты

| Вариант            | Split      | Average Precision | EPIC Spearman | Примечание                                                  |
| ------------------ | ---------- | ----------------: | ------------: | ----------------------------------------------------------- |
| constant reference | validation |       0.000670644 |      0.000000 | AP = prevalence; Spearman = 0 по явной no-ranking конвенции |
| dinucleotide LR    | validation |   **0.001330258** |  **0.090720** | полная validation-оценка                                    |
| Δ                  | validation |  **+0.000659614** | **+0.090720** | AP = **1.9836×** reference                                  |

| `NC_064034.1` | 0.000693067 | 0.001427969 | 0.101741 |

LBFGS сошёлся за 15 из 350 итераций без предупреждений; fit занял около
0.09 секунды после полного подсчёта категорий. Наибольшие положительные
коэффициенты относительно `TT` получили `CA`, `CG` и `TA`.

## Интерпретация

Минимальный последовательностный сигнал реален и переносится на все три
удержанные contig: AP увеличился примерно вдвое, а ранжирование интенсивности
получило положительную корреляцию. Одновременно абсолютный AP остаётся низким,
что ожидаемо при prevalence `0.067%` и всего 17 score-уровнях.

Ограничения:

- `C=1` ещё не подбирался;
- class balancing означает, что scores не являются калиброванными
  вероятностями;
- у `lbfgs` нет опубликованной истории objective, поэтому loss-by-epoch не
  строился; вместо него сохранена честная диагностика сходимости;
- нулевая Spearman reference — договорённость для отсутствующего ранжирования,
  а не математически определённая корреляция константы.

## Решение

`adopt` — использовать EXP-001 как воспроизводимый reference для следующего
контролируемого эксперимента. Это принятие baseline, а не утверждение, что
двух букв или `C=1` достаточно для финальной модели.
