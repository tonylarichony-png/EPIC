# EPIC — последние обучения Global-моделей и результаты

> Обновление по серии экспериментов после EXP020.  
> Фокус: понять, насколько Global detector упирается в недообучение, размер регионов, multi-head objective и Multi-Scale Tower.

---

## 1. EXP020 — длинное обучение базовой Global-модели

### Архитектура

```text
BPE200
target = 2048 bp
flank = ±6144 bp
input = 14336 bp

Global backbone:
32 channels
dilations = 1,2,4,8,16,32,64,128,256,512
RF = 4093 BPE tokens

regional heads:
256 / 128 / 64 / 32 bp
```

Главный вопрос:

> AP около 0.10 был потолком архитектуры или модель просто была недообучена?

Запуск планировался до 100k, но kernel умер примерно на 96.2k. Сохранились checkpoints:

```text
10k / 25k / 50k / 75k
```

### Holdout learning curve

| Steps | AP256 | AP128 | AP64 | AP32 |
|---:|---:|---:|---:|---:|
| 10k | 0.245572 | 0.182853 | 0.136645 | 0.099555 |
| 25k | 0.289298 | 0.221892 | 0.169294 | 0.127385 |
| 50k | **0.301528** | **0.231251** | **0.176626** | 0.132097 |
| 75k | 0.295394 | 0.227437 | 0.174291 | **0.132761** |

Для 32-bp head AP lift:

```text
10k  → 9.109×
25k  → 11.656×
50k  → 12.087×
75k  → 12.148×
```

### Вывод

- 10k действительно было мало.
- Основной прирост идёт до 25–50k.
- После 50–75k начинается плато.
- 256/128/64 heads уже деградируют после 50k.
- 32-bp head ещё чуть растёт, но очень медленно.

Это стало первым сигналом, что дополнительные regional heads могут конкурировать за backbone representation.

## 2. EXP026 — только 32 bp + 16 bp

### Гипотеза

Убрали:

```text
256 / 128 / 64
```

и оставили:

```text
32 / 16 bp
```

Backbone остался таким же, как в EXP020.

Запуск снова упал примерно на 46.2k, последний безопасный checkpoint — 45k.

Training EMA:

```text
32 bp = 0.651622
16 bp = 0.533117
total = 0.592370
```

### Holdout @45k

| Region | Prevalence | AP | AP lift |
|---:|---:|---:|---:|
| 32 bp | 0.010929 | **0.143319** | 13.113819× |
| 16 bp | 0.006305 | 0.111068 | **17.616880×** |

|---:|---:|

| 2% | 43.45% |
| 5% | 58.76% |
| 10% | **71.74%** |

| 50% | 96.23% |

#### 16 bp

| Selected regions | TSS recall |

### Доля регионов для target recall

#### 32 bp

| Target recall | Selected fraction |
|---:|---:|
| 90% | 29.09% |
| 95% | **44.22%** |
| 99% | 72.66% |

#### 16 bp

| Target recall | Selected fraction |
|---:|---:|
| 90% | 28.75% |

### Вывод по 16 bp

16 bp действительно немного лучше по recall-vs-budget, но улучшение очень маленькое.

```text
32 → 16 bp
число регионов:
2.56 млн → 5.18 млн
```

При этом:

```text
top10 TSS recall:
71.74% → 72.15%
+0.41 п.п.

95% TSS recall budget:
44.22% → 43.48%
-0.74 п.п.
```

Поэтому 32 bp остаётся более рациональным coarse scale.

## 3. Главный эффект EXP026 — удаление coarse heads помогло 32-bp head

```text
AP32 @75k = 0.132761
```

```text

```


```text
256/128/64 heads
```

## 4. EXP027 — Gated Multi-Scale Tower + только 32-bp head

### Цель

Проверить архитектуру EXP025 при длинном обучении и без лишних regional heads.

Архитектура:

```text
BPE200
↓
stem
├─ strong EXP020 backbone
│  d=1,2,4,8,16,32,64,128,256,512
│  RF=4093
│
└─ Multi-Scale Tower
   ×4
   ×16
   ×64
   ×256
↓
fused =
strong
+ g4   * tower_x4
+ g16  * tower_x16
+ g64  * tower_x64
+ g256 * tower_x256
↓
32-bp head only
```

Начальные gates:

```text
g4 = g16 = g64 = g256 = 0.01
```

Обучение:

```text
100k steps
```

Checkpoints сохранялись каждые 2.5k.

## 8. Что мы теперь знаем

### Training budget

Оптимальная зона сейчас:

```text
50k–75k
```

10k — мало.

100k — уже может ухудшать holdout.

### Лучший coarse scale

```text
32 bp
```

16 bp даёт слишком маленький выигрыш относительно удвоения числа регионов.

### Multi-head objective

Есть сильные признаки, что головы:

```text
256 / 128 / 64
```

мешают 32-bp задаче.

### Tower

Полный multi-scale tower не дал преимущества.

Но gate-анализ показал важную вещь:

```text
×4 scale полезен
```

Это может пригодиться для более простой будущей архитектуры:

```text
strong backbone + one ×4 auxiliary branch
```

## Краткий итог

Последние обучения дали четыре сильных вывода:

```text
1. 10k steps мало.
2. 50–75k — разумный training budget.
3. 32 bp — лучший practical region scale.
4. Удаление лишних regional heads помогло сильнее, чем усложнение Tower.
```

Текущий лучший результат:

```text
EXP026 @45k

AP32 = 0.143319
top10% regions → 71.74% TSS
95% recall → 44.22% regions
```

Tower дал полезную диагностическую информацию про ×4 scale, но пока не дал лучшего Global detector.
