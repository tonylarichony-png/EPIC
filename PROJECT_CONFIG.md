# Настройка проекта

Отметьте разделы, которые нужны этому проекту. Подключённые документы обновляются автоматически в Live Preview и режиме чтения.

## Постановка задачи

- [ ] Показывать бизнес-контекст в [[docs/00_problem.md]] ^show-business-context

## Данные

- [ ] Показывать раздел Privacy и безопасность в [[docs/01_data.md]] ^show-data-privacy

## EDA

- [ ] Показывать памятку с правилами исследования в [[docs/02_eda.md]] ^show-eda-guidelines

> [!info]
> Снятая галочка исключает раздел из рабочего документа, но не удаляет его содержимое. Установленная галочка возвращает обычный редактируемый Markdown.
>
> Изменение применяется, когда целевой документ открыт или открывается в Live Preview / режиме чтения.

## Как добавить новую условную секцию

1. Сохраните исходный текст в папке `sections`.
2. Добавьте отдельную галочку с уникальным block ID.
3. Подключите `system/conditional-section` в нужном документе по примеру [[docs/00_problem.md]].
