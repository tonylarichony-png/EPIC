> [!abstract] Цель
> Динуклеотидные взаимодействия в ±5 bp дополняют pos51. Для shortlist требуются относительный прирост среднего по 3 folds weighted sampled AP ≥5% к pos51, нижняя граница 95% парного bootstrap-интервала среднего по контигам ΔAP >0 и сходимость. Иначе outcome iterate.

### Изменение

- **Что меняем:** Добавить к pos51 индикаторы соседних динуклеотидов внутри диапазона [-5,+5] и сравнить с тем же pos51.
- **Что остаётся фиксированным:** позиции, folds, label, sampling, seed, базовое кодирование, алгоритм, регуляризация и веса.
- **Почему ожидаем эффект:** Точный прежний train-аудит показал CA enrichment 2.90625× в [-1,0]; аддитивные эффекты одиночных оснований не обязаны описывать взаимодействие.
- **Критерий успеха:** Для shortlist требуются относительный прирост среднего по 3 folds weighted sampled AP ≥5% к pos51, нижняя граница 95% парного bootstrap-интервала среднего по контигам ΔAP >0 и сходимость. Иначе outcome iterate.
- **Guardrails:** Сходимость, поддержка редких пар, одинаковая выборка и folds, AP по контигам и dense-rank корреляция. Знак условного коэффициента не трактовать как причинный эффект.
- **Бюджет / stop condition:** 1 новый кандидат × 3 folds; pos51 можно взять из будущей проверки IDEA-001. Максимум 350 итераций каждого fit. Полная серия: 13 кандидатов × 3 folds; full-train refit не выполняется.

### Features

- **Feature set / version:** Позиционные основания 51 bp + произведения non-T индикаторов A/C/G/N для 10 соседних пар [-5,-4]…[+4,+5]; по 16 взаимодействий на пару, всего 160 дополнительных признаков.
- **Preprocessing:** все fit-преобразования только на обучающих контигах fold; StandardScaler для composition с training weights. DNA ориентирована по цепи. Коэффициенты долей переводятся в исходную шкалу на +0.10 (10 п.п.).
- **Изменения к baseline:** Добавить к pos51 индикаторы соседних динуклеотидов внутри диапазона [-5,+5] и сравнить с тем же pos51.

### Model

- **Алгоритм / параметры:** LogisticRegression, L2, C=1, solver=lbfgs, max_iter=350, tol=1e-4.
- **Initialization / pretrained version:** обучение с нуля; **seed:** 42.

### Guardrails и сегменты

Планируется проверить сходимость, поддержку редких пар и обе метрики по folds/contig. Знак коэффициента не трактовать как причинный эффект.

### Стабильность

Парные сравнения на одинаковых OOF-позициях; 200 bootstrap-повторов по 12 контигам, 95% percentile-интервал среднего парного ΔAP по контигам (macro). Интервал условен на fitted OOF и выбранных строках: без refit и повторного sampling. Это иной estimand, чем mean fold AP; интервалы остаются исследовательскими.
