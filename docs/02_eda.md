## Текстовые признаки

Первичный обзор выполняется в разделе «Первичный обзор текстового признака» notebook [[notebooks/02_eda_hypotheses.ipynb]]. Здесь сохраняйте короткий итог трёх базовых проверок, а не полные таблицы вывода.

| Признак | Что видно в примерах | NaN / пустые / спецсимволы | Уникальность / точные повторы | Предварительный тип | Следующий шаг / ссылка |
|---|---|---|---|---|---|
|  |  |  |  | категория / идентификатор / структурированная строка / свободный текст / непонятно |  |

Заполняйте столбцы так:

- **Что видно в примерах** — общий вид значений после просмотра первых и случайных строк.
- **NaN / пустые / спецсимволы** — количество или доля проблемных состояний и важные найденные символы.
- **Уникальность / точные повторы** — доля уникальных значений, покрытие top-20 и наличие повторяющихся полных строк.
- **Предварительный тип** — текущая классификация поля, которая ещё может измениться после дополнительной проверки.
- **Следующий шаг / ссылка** — нужен ли углублённый анализ, перенос в другую `FEATURE_GROUPS` или ссылка на карточку из [[eda/findings/_index.md]].

## Сохранённые EDA-наблюдения

Важный график или таблицу можно сохранить из [[notebooks/02_eda_hypotheses.ipynb]] вместе с методом и выводом. Notebook создаст отдельную карточку в [[eda/findings/_index.md]] и автоматически обновит список ниже. Небольшая таблица встраивается в карточку полностью, большая получает Markdown-preview и полный CSV в `assets/eda/`.

Эксперименты, основанные на наблюдении, появляются в его карточке автоматически. Источник связи — поле `eda_findings` во frontmatter карточки эксперимента; после его изменения выполните `sync-experiment-state.cmd` из корня проекта. Эта же команда синхронизирует `decision`; переобучение модели не требуется.
